# Contact Book Application

## Project Description

The Contact Book Application is a Python-based project that helps users manage contact information. Users can add, view, search, update, delete, and sort contacts. The application also saves contact details in a JSON file so they can be loaded again when the program restarts.

## Features

* Add new contacts
* View all contacts
* Search contacts by name or phone number
* Update existing contact details
* Delete contacts
* Sort contacts alphabetically by name
* Save contact details to a JSON file
* Load previously saved contacts automatically
* Prevent duplicate phone numbers

## Technologies Used

* Python
* Object-Oriented Programming (OOP)
* Classes and Objects
* Lists
* Functions and Methods
* File Handling
* JSON

## Requirements

* Python 3.x
* Visual Studio Code or another Python editor

No external Python libraries are required.

## How to Run the Project

1. Download or clone the project folder.
2. Open the folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

```bash
python contact_book.py
```

5. Select an option from the menu and follow the instructions.

## Data Storage

Contact information is stored in a file named `contacts.json`. The application uses Python's built-in `json` module to save and load contact details.
